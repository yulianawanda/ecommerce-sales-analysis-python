# ecommerce-sales-analysis-python
Final Project Python - MySkill Bootcamp
## Overview
This project is a data analysis project completed as part of the Data Analysis Bootcamp at MySkill.
The project focuses on processing and analyzing an e-commerce dataset using Python in Google Colab.
## Dataset
The dataset used in this project is the Pakistan's Largest E-commerce Dataset.
## Tools
- Python
- Google Colab
- Pandas
## Analysis
The analysis includes:
- Data loading and inspection
- Data cleaning and praprocessing
- Data manipulation using Pandas
- Exploratory data analysis
- Extracting insights from the dataset
